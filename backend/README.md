# Бэкенд: PocketBase

Хранит цвета, цены, классы багажника, фото, отзывы и настройки. Админка: `/_/`.

## Запуск локально

1. Скачайте PocketBase (linux amd64) с https://github.com/pocketbase/pocketbase/releases
   и положите бинарник `pocketbase` в эту папку (он в `.gitignore`).
2. `./pocketbase superuser upsert you@example.com 'надёжный-пароль'`
3. `./pocketbase serve --http=127.0.0.1:8090` — миграции применятся сами и создадут
   коллекции и начальные данные (11 цветов, 4 класса багажника, настройки).
4. Админка: http://127.0.0.1:8090/_/

## Коллекции

| Коллекция | Что хранит | Публично видно |
|---|---|---|
| `colors` | название, hex, где применять (коврик/кант/оба), порядок, `active` | только `active = true` |
| `trunk_classes` | класс багажника и площадь в м² | все |
| `photos` | фото работ, подпись, порядок | все |
| `reviews` | отзывы, фото, `visible` | только `visible = true` |
| `settings` | одна запись: название, WhatsApp, срок, цены, тексты | да |

Запись, изменение и удаление доступны только суперпользователю.
