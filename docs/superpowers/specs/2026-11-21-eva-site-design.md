# Сайт EVA-ковриков с конфигуратором цвета — проект

Дата: 2026-11-21

## Зачем

У владельца есть цех: ручная резка EVA-ковриков и пошив канта (окантовки). Нужен сайт, где покупатель
выбирает набор и цвета (коврик + кант, цветов 10+), сразу видит результат на схеме салона и отправляет
готовую заявку владельцу в WhatsApp. Владелец сам, без программиста, меняет цвета, цены, фото и отзывы
через админку.

Главное отличие от конкурентов: живое превью с независимой перекраской коврика и канта
(10+ x 10+ комбинаций).

## Цели

- Выбор набора: водитель, передний пассажир, задний ряд, багажник, перемычка; готовые пакеты.
- Превью салона сверху (SVG): коврик и кант перекрашиваются отдельно, цена пересчитывается сразу.
- Заказ в WhatsApp: сообщение формируется само (набор, цвета, цена, срок).
- Доверие: галерея работ из цеха, отзывы, процесс изготовления.
- Запрос образцов цветов (отдельная кнопка, тоже через WhatsApp).
- Админка: цвета, наборы и цены, срок изготовления, галерея, отзывы, номер WhatsApp и тексты.
- Работает на телефоне в первую очередь (заказы идут из мессенджеров).

## Не цели

- Подбор по базе авто (марка/модель/год из списка). Вместо этого в заявке обычное поле для ввода.
- SEO-страницы под каждую модель авто.
- Корзина и онлайн-оплата.
- Журнал заказов в админке (возможно позже).
- Личные кабинеты покупателей.

## Антицели (провал, даже если всё работает)

- Превью, которое выглядит неубедительно или цвета на нём заметно отличаются от реальных.
- Владельцу нужен программист, чтобы поменять цену или цвет.
- Медленная загрузка на мобильном интернете.

## Ограничения

- У владельца есть VPS для сервера.
- Производство ручное: срок изготовления выводится на сайте и редактируется в админке.
- Бюджет маленький: минимум поддержки, один маленький сервер.

## Подходы

1. **PocketBase + лёгкий сайт (выбрано).** PocketBase даёт готовую админку, базу SQLite и загрузку
   файлов одним бинарником. Минимум поддержки. Минус: админка стандартная, без своего дизайна.
2. Next.js со своей админкой. Полный контроль, но админку писать и поддерживать самому ради функций,
   которых в PocketBase уже хватает.
3. Статика + Decap CMS (через Git). Хостинг бесплатный, но правки превращаются в коммиты, а загрузка
   фото неудобна для не-программиста.

Выбрано 1: готовая админка, один маленький сервер, превью на SVG не зависит от фреймворка.

## Решения (как решил владелец)

- Нужна админка.
- Из идей: набор (2), превью по цветам (3), заказ в WhatsApp (6), доверие (7), образцы (8).
- Автоподбор по авто и SEO-страницы не нужны.
- Деплой на VPS владельца.

## Мои решения (проверить)

- Фронтенд: Astro без тяжёлых библиотек, превью на чистом SVG + немного JS.
- Сайт берёт данные из PocketBase API; если сервер недоступен, показывает последние сохранённые данные.
- В заявке поле «марка, модель, год, руль» заполняется вручную. Праворульные авто в регионе
  частые, поэтому поле руля обязательное.
- Язык: русский. Кыргызский добавляется позже через файл переводов.
- Строка «Срок изготовления: N дней» на странице и в сообщении WhatsApp.
- Коллекции в админке: цвета (название, hex, для чего: коврик/кант/оба), пакеты (состав, цены),
  фото, отзывы, настройки.
- Веб-сервер: Caddy перед PocketBase (HTTPS автоматически).

## Оставлено исполнителю

- Форма схемы салона (точные контуры ковриков для SVG).
- Визуальный стиль сайта (тёмная или светлая тема, шрифты): аккуратно, без «шаблонности».
- Структура сообщения WhatsApp в деталях.
- Скрипт развёртывания и резервного копирования базы.

## Данные от владельца (2026-11-21)

- Название магазина: **Ева Тоха**.
- Цвета для старта: «все цвета радуги». Мой вариант: красный, оранжевый, жёлтый, зелёный, голубой,
  синий, фиолетовый, плюс ходовые чёрный, серый, белый, розовый (11 цветов). Меняется в админке.
- Цены (валюта предположительно сом), полный набор салона БЕЗ багажника: с бортами — 2200;
  без бортов — 1700.
- Багажник: 1300 сом за м² израсходованного материала. Итоговая цена зависит от площади, которая
  зависит от машины. Цена за м² хранится в настройках админки.
- Цены отдельных ковриков — не заданы; пока продаём только наборы салона + багажник по выбору.
- Модель: «борты» (высокие бортики коврика) — отдельная опция цены, не путать с кантом (цвет окантовки).
